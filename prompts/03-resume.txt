# PLANRO — RESUME ONE SCOPE

قرارداد اصلی در `01-start-province.txt` است.

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
scope_id=<SCOPE_ID>
previous_id=<PREVIOUS_ID>
```

State فعلی را از MCP بخوان و از اولین مورد ناقص بعد از previous_id ادامه بده. کار کامل را بی‌دلیل تکرار نکن.
همه قواعد Normalize فیلدها، ownership هزینه/FAQ/Checklist، taxonomy، sources/evidence و media مستقل را حفظ کن.
سؤال تعاملی نپرس. بعد از تکمیل همان Scope متوقف شو.
