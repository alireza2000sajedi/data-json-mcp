# Planro Agent — Prompt 03: Resume One Scope

Required user input:
- `province_id=<PROVINCE_ID>`
- `scope_id=<SCOPE_ID>`

Normalize numeric province ids internally to canonical `province-{n}`. Do not request a derived Province Scope id.
Do not ask follow-up questions. The required variables are supplied in the RUN VARIABLES block at the end of this file.
If a required variable is empty, STOP with `MISSING_INPUT: <variable>`. If MCP is unavailable, report the connection/setup problem and STOP.

Workflow:
1. Verify the exact Scope exists and belongs to the Province.
2. Read current Scope state, pending nodes, source coverage, candidates, conflicts, media deficits and saved Entities through MCP.
3. Continue from the first genuinely incomplete item.
4. Do not restart completed research unless evidence is invalid/outdated or validation requires correction.
5. Preserve scope isolation: do not process siblings.
6. Follow the same schema, taxonomy, source, safety, media, cost and save rules as Prompt 02.
7. Finish with `check_definition_of_done` and validation.
8. Stop after the supplied Scope is complete.
