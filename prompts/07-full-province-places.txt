# PLANRO — FULL PROVINCE PLACES

تکمیل **همهٔ Placeها** در کل استان وقتی Province/County/City از قبل شروع شده‌اند.
فقط `province_id`. Scope جدا از کاربر نخواه.

قرارداد مادر: `01-start-province.txt`.

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
```
- مقدار واقعی در Task authoritative است.
- نبود → `MISSING_INPUT: province_id` و توقف.

---

## 1) هدف
1. هر `county-*` را پیمایش کن.
2. Placeهای مستقیم شهرستان (`countyPlaces`) را کامل کن.
3. هر `city-*` داخل شهرستان و Placeهایش را کامل کن.
4. محل کمپ = Place (`campground`) — Entity جدا نساز.

تمرکز Place است. اداری‌ها را فقط اگر برای کشف/ذخیرهٔ Place لازم‌اند تعمیر کن.

---

## 2) قفل — کل استان یک‌سره
1. `import_province_scopes` اگر لازم است.
2. `set_active_scope(provinceId)` — continuous؛ برای Scope بعدی نایست.
3. صف: `list_pending_nodes({ provinceId, allScopes: true })` + `get_next_research_node`.
4. ترتیب DFS را حدس نزن.

```text
output/{province_id}/
└── county-*/ 
    ├── place-*.json
    └── city-*/place-*.json
```

---

## 3) کار هر واحد
1. `get_node_context`
2. `discover_subtree` برای Place
3. ۵ Primary + `get_source_coverage` → satisfied
4. Place با `place-{p}-{n}` از طریق `save_active_entity`
5. `complete_discovery_task`: county→`countyPlaces` (+ districts/ruralDistricts با ۰ اگر خالی) · city→`places`
6. Media Place=۴؛ به‌محض target توقف؛ URL reuse ممنوع

---

## 4) پایان
1. `pendingByType.place` و trackهای Place باز = ۰
2. `check_definition_of_done` → `complete:true`
3. `validate_province` → `invalid:0`
4. اگر DoD به‌خاطر اداری ناقص است همان را در همین ران تعمیر کن

ممنوع: توقف بعد از یک county · پرسیدن Scope بعدی · save بدون MCP · commit با fail

---

## 5) تحویل
گزارش: counties، cities، places، taxonomy staging  
سپس git add/commit/push فقط اگر DoD و validate پاس شد.
