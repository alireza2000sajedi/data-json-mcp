# PLANRO — MEDIA GAP AUDIT

تکمیل عکس Entityهایی که صفر یا زیر targetاند.
فقط `province_id`. قرارداد مادر: `01-start-province.txt`.

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
```
- مقدار واقعی authoritative است؛ نبود → `MISSING_INPUT: province_id`.
- اختیاری: `node_types=place` یا `only_zero=true`.

---

## 1) Target
| نوع | عکس یکتا |
|---|---|
| Province | ۵ |
| County | ۳ |
| City | ۳ |
| Place | ۴ |

وضعیت‌ها: **zero** · **below_target** · **bad_status** · **reuse**

---

## 2) اسکن
1. `import_province_scopes` / `set_active_scope(provinceId)` اگر لازم
2. همهٔ Entityهای `output/{province_id}/` را بخوان
3. جدول بساز: `entityId | nodeType | imageCount | target | gap | status`
4. گزارش اولیه **قبل از تعمیر**

`imageCount` = URL یکتا در thumbnail + images.

---

## 3) رفع
برای zero / below_target / bad_status / reuse:
1. `get_node_context`
2. جست‌وجوی تصویر (Commons، رسمی، خبرگزاری، …) — محدود به Primary نباش
3. `record_media_candidate` → `finalize_media` → `save_active_entity`
4. تا target؛ URL reuse ممنوع
5. `mark_node_media_deficit` فقط وقتی هیچ Entity قابل ذخیره نیست

متن/FAQ را بازنویس نکن مگر برای save لازم باشد.

---

## 4) پایان
- zero و below_target (مگر only_zero) و reuse برطرف
- `validate_province` → `invalid:0`
- DoD در صورت امکان `complete:true`؛ اگر گیر غیرmedia بود جدا گزارش بده

```text
scanned / zero_fixed / below_target_fixed / still_zero / still_below / reuse_fixed
```

Commit فقط بعد از پاس media معنادار.
