# PLANRO — RUN ONE SCOPE

قرارداد اصلی در `01-start-province.txt` است. فقط همین Scope را اجرا کن.

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
scope_id=<SCOPE_ID>
```
اگر در Task جاری مقدار واقعی `scope_id` آمده باشد، همان authoritative است و placeholder بالا نادیده گرفته می‌شود؛ در نبود مقدار واقعی `MISSING_INPUT: scope_id` بده و متوقف شو.

- MCP و Resourceها را بررسی کن.
- Scope را دقیقاً lock کن و فقط subtree مجاز آن را اجرا کن.
- Field policy را از `planro://rules/entity-fields` بخوان.
- Visit/Costs/FAQ/Checklist/Media باید متعلق به همان Entity باشند.
- برای Province/County/City openingHours و child-specific entryFee ذخیره نکن.
- برای Parent هزینه Child یا FAQ Child ذخیره نکن.
- هر Entity checklist مستقل خودش را داشته باشد.
- Media: Province/County/City/Place = 5؛ Village/Camping = 3؛ بدون URL تکراری بین Entityها.
- پنج Primary Source را واقعاً جست‌وجو و با `record_search_result` ثبت کن؛ Media جای Source Coverage نیست.
- فقط canonical taxonomy IDs را استفاده کن.
- Save فقط با MCP؛ سپس DoD + validation و توقف.

اگر متغیر ناقص است `MISSING_INPUT: <variable>` بده؛ سؤال نپرس.
