# PLANRO — RUN ONE SCOPE

قرارداد مادر: `01-start-province.txt` (schema، sources، media، taxonomy، متن، TURBO، Ownership، سلسله‌مراتب).
این پرامپت فقط **یک Scope** را اجرا می‌کند.

یک Scope = کل زیردرخت آن واحد (خود واحد + فرزندان اداری + Placeها)، نه فقط ریشه.
Scope مجاز: **County** | **City** | **Village** — فقط از `planro://scopes/{provinceId}` (input).

---

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
scope_id=<SCOPE_ID>
```
- مقدار واقعی در Task authoritative است.
- نبود `scope_id` → `MISSING_INPUT: scope_id` و توقف؛ سؤال نپرس.
- نبود `province_id` → `MISSING_INPUT: province_id`.
- عدد استان را به `province-{n}` normalize کن.
- نام فارسی را با `indexByName` به id قطعی تبدیل کن؛ در ابهام `expectedType` بگذار.

---

TURBO از پرامپت ۰۱: تحقیق موازی OK؛ save خطی؛ media در target؛ track خالی با count 0.

## 1) قفل Scope
1. Resourceها / MCP طبق ۰۱ (اگر آماده است تکرار بی‌نیاز).
2. `import_province_scopes(provinceId)` اگر notes نیست.
3. `set_active_scope({ provinceId, nodeId: scope_id })` — فقط همین subtree.
4. صف: `list_pending_nodes` (پیش‌فرض Scope فعال). `allScopes:true` فقط برای گزارش، نه کار خارج از Scope.
5. ترتیب DFS را از `get_next_research_node` بگیر؛ حدس نزن.

---

## 2) چه چیزی کامل شود
داخل Scope فعال، تا pending مربوطه صفر شود:

| اگر Scope = | کامل کن |
|---|---|
| County | خود County + همه Cityها + Villageهای شهرستان/زیرشهر + Placeهای مستقیم و تو در تو |
| City | خود City + Villageهای زیر این City + Placeهای City و Villageها |
| Village | خود Village + Placeهای زیر همین Village |

- محل کمپ = Place (`campground`)؛ Entity جدا نساز
- واحد جدید خارج از input نساز

Media: County=۳ · City=۳ · Village=۲ · Place=۴ — به‌محض target توقف؛ URL reuse ممنوع
**فقط URL** — دانلود/ذخیرهٔ فایل تصویر ممنوع؛ فقط `imageUrl` در Entity.

Discovery tracks:
- county: `cities` / `villages` (از import) · `countyPlaces` · `districts`/`ruralDistricts` خالی با `0`
- city: `places` · `villages` (اگر در input زیر city آمده)
- village: `places`

---

## 3) حلقه کار (هر Node) — کیفیت نهایی همان‌جا
1. `get_node_context(nodeId)` — `placesChecklist` فقط از input
2. در صورت اداری: `discover_subtree` فقط برای trackهای مجاز
3. `record_search_result` × ۵ Primary تا `get_source_coverage` → `satisfied:true`
4. media → `finalize_media` **تا target** (پاس media جدا ممنوع؛ فقط URL — دانلود فایل ممنوع)
5. متن نهایی انسانی (§۸ پرامپت ۰۱) — بازنویسی بعدی فرض نکن
6. `save_active_entity({ provinceId, entity, expectedNodeId })` — فقط MCP
7. اگر save/validate خطا داد → **همان Node را تعمیر کن**؛ ناقص رد نشو
8. `complete_discovery_task` با count واقعی

TURBO: تحقیق موازی OK؛ save خطی؛ بدون حذف Source/Place.

Location: اگر ScopeUnit در `planro://scopes` فیلد `location` داشت، همان را برای Entity استفاده کن.

### سلسله‌مراتب (یادآوری)
- فقط واحدهای input / scopes
- Village Parent = County یا City — نه Province تنها
- **روستا Place نیست:** Village را کامل کن؛ جاذبه را Place زیر Village بگذار؛ نام روستا را Place ننویس
- در Entity: `location.province/county/city/village` مطابق زنجیره

---

## 4) پایان Scope
1. `list_pending_nodes` برای Scope فعال → کار باز نمانده
2. `check_definition_of_done(provinceId)` → `complete:true` (نسبت به Scope فعال)
3. `validate_province(provinceId)` → `invalid:0`
4. متوقف شو؛ Scope بعدی را خودکار انتخاب نکن
