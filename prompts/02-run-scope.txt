# PLANRO — RUN ONE SCOPE

قرارداد مادر: `01-start-province.txt` (schema، sources، media، taxonomy، متن، TURBO، Ownership).
این پرامپت فقط **یک Scope** را اجرا می‌کند.

یک Scope = کل زیردرخت آن واحد (خود واحد + شهرها/Placeهایش)، نه فقط ریشه.
Scope مجاز: **County** یا **City** (از `planro://scopes/{provinceId}`).

---

### RUN VARIABLES
```text
province_id=<PROVINCE_ID>
scope_id=<SCOPE_ID>
```
- مقدار واقعی در Task authoritative است.
- نبود `scope_id` → `MISSING_INPUT: scope_id` و توقف؛ سؤال نپرس.
- نبود `province_id` → `MISSING_INPUT: province_id`.
- عدد استان را به `province-{n}` normalize کن.
- نام فارسی را با `indexByName` به id قطعی تبدیل کن؛ در ابهام `expectedType` بگذار.

---

TURBO SPEED / SPEED MODE از پرامپت ۰۱: تحقیق موازی OK؛ save خطی؛ media در target؛ track خالی با count 0.

## 1) قفل Scope
1. Resourceها / MCP طبق ۰۱ (اگر آماده است تکرار بی‌نیاز).
2. `import_province_scopes(provinceId)` اگر notes نیست.
3. `set_active_scope({ provinceId, nodeId: scope_id })` — فقط همین subtree.
4. صف: `list_pending_nodes` (پیش‌فرض Scope فعال). `allScopes:true` فقط برای گزارش کل استان، نه برای کار خارج از Scope.
5. ترتیب DFS را از `get_next_research_node` بگیر؛ حدس نزن.

---

## 2) چه چیزی کامل شود
داخل Scope فعال، تا pending مربوطه صفر شود:
- خود County یا City
- همهٔ Placeهای مستقیم و زیر شهرهای داخل همان Scope
- محل کمپ = Place (`campground` + taxonomy مرتبط)؛ Entity جدا نساز

Media:
- County=۳ · City=۳ · Place=۴
- به‌محض target متوقف شو؛ URL reuse ممنوع

Discovery tracks:
- county: `countyPlaces` (+ `districts`/`ruralDistricts` خالی با `count:0`)
- city: `places`
- شهرهای داخل county از import آمده‌اند؛ deep-research هر city داخل Scope را انجام بده

---

## 3) حلقه کار (هر Node)
1. `get_node_context(nodeId)`
2. در صورت اداری: `discover_subtree`
3. `record_search_result` × ۵ Primary تا `get_source_coverage` → `satisfied:true`
4. media → `finalize_media` تا target
5. `save_active_entity({ provinceId, entity, expectedNodeId })` — فقط MCP
6. `complete_discovery_task` با count واقعی

TURBO: تحقیق موازی OK؛ save خطی؛ بدون حذف Source/Place.

متن: انسانی، بدون OTA (بخش ۸ پرامپت ۰۱).

---

## 4) پایان Scope
1. `list_pending_nodes` برای Scope فعال → کار باز نمانده
2. `check_definition_of_done(provinceId)` → `complete:true` (نسبت به Scope فعال)
3. `validate_province(provinceId)` → `invalid:0`
4. متوقف شو؛ Scope بعدی را خودکار انتخاب نکن

---

## 5) تحویل
1. اگر DoD/validate پاس نشد → **commit ممنوع**
2. پس از پاس: `git status --short output/` → `git add output/` → commit → `git push`

گزارش کوتاه: scope_id، تعداد city/place کامل‌شده، taxonomy staging.
