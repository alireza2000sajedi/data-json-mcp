# Planro Agent — Prompt 04: Repair One Entity

Required user input:
- `province_id=<PROVINCE_ID>`
- `scope_id=<SCOPE_ID>`
- `entity_id=<ENTITY_ID>`

Normalize numeric province ids internally to canonical `province-{n}`. Do not ask for a derived Province Scope id.
Never invent or substitute an Entity id.
Do not ask follow-up questions. The required variables are supplied in the RUN VARIABLES block at the end of this file.
If a required variable is empty, STOP with `MISSING_INPUT: <variable>`.
If MCP is unavailable, report the connection/setup problem and STOP.

Workflow:
1. Verify the exact Province, Scope and Entity exist and the Entity belongs to the selected Scope.
2. Read the stored Entity and the current schema/taxonomy/source/brand rules.
3. Identify every blocking defect: schema mismatch, taxonomy violation, hierarchy mismatch, unsupported claim, source/evidence gap, invalid media, cost problem, relation problem, safety problem, forbidden field or user-facing research leakage.
4. Repair only the selected Entity and only what is justified by current evidence.
5. Never invent missing facts.
6. Save only through MCP.
7. Re-run validation and Scope DoD.
8. Stop after the selected Entity is valid.
