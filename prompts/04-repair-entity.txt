# Prompt 04 — Repair One Entity

ورودی Runner:
- province_id
- scope_id
- entity_id

هدف: فقط Entity مشخص‌شده را اصلاح کن.

1. Entity، node context، schema، taxonomy، source-policy و quality errors فعلی را بخوان.
2. خطاها را بر اساس اولویت اصلاح کن: schema → taxonomy → hierarchy → sources/evidence → content → media → costs/checklist → brand voice.
3. Factی که منبع معتبر ندارد حدس نزن؛ در صورت نیاز دوباره research کن.
4. `tags` و `safety.emergencyNumbers` را هرگز نگه ندار.
5. taxonomy فقط canonical ID باشد؛ proposal برای تولید مجاز نیست.
6. لینک‌ها raw HTTPS باشند.
7. بعد از repair با `save_active_entity` ذخیره کن.
8. سپس `validate_province` را اجرا کن و مطمئن شو خطای همان Entity صفر شده است.

Repair نباید داده سایر Scopeها را تغییر دهد مگر Relation دوطرفه‌ای که قانون پروژه آن را الزام می‌کند.
