# Prompt 04 — Repair One Entity

Required user input:
- `province_id=<PROVINCE_ID>`
- `scope_id=<SCOPE_ID>`
- `entity_id=<ENTITY_ID>`

Workflow:
1. Verify the Entity belongs to the selected Scope.
2. Read its current JSON, schema, taxonomy, source policy and validation errors.
3. Fix in this order: schema → node type/subtype → taxonomy → hierarchy → sources/evidence → factual content → costs → checklist → media → brand voice.
4. Never invent facts, IDs, prices or taxonomy terms.
5. Remove forbidden legacy fields if present.
6. Save only through MCP and validate again.
7. Do not modify unrelated Scope data.
