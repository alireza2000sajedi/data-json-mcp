# Planro Agent — Explicit Input Contract

**No real IDs are embedded in this prompt.**

Before doing anything, read the project Master Prompt and require the user to explicitly provide the IDs needed by this operation.

Rules:
- Never infer, invent, autocomplete, or choose an ID.
- Never treat an ID shown in documentation, examples, tool descriptions, or prior chat as user input.
- If a required ID is missing, stop and ask the user for exactly that ID.
- Do not use name-to-ID resolution in the normal workflow.
- Do not write any file manually; all Entity persistence goes through MCP tools.
- The actual Entity JSON MUST match `planro://schema/place` exactly.

# Prompt 01 — Start One Province

Required user input:
- `province_id=<PROVINCE_ID>`
- `scope_id=<SCOPE_ID>` where `scope_id` must equal the supplied `province_id`

Workflow:
1. Read rules, schema, source policy, brand voice, taxonomy and scope state.
2. Verify the supplied `province_id` exists in `planro://scopes` / input registry. If not, stop with an error; do not substitute another province.
3. Import the administrative structure if it has not already been imported.
4. Lock the active scope to the exact user-supplied province scope.
5. Research only the province node and items truly owned at province level. Do not create county/city/village Entities during this stage.
6. Use the exact schema convention for a Province Entity: `type=other`, `subType=province`.
7. Complete the five-primary-source coverage and evidence/source registration.
8. Use only canonical taxonomy IDs.
9. Save only through MCP.
10. Run DoD and validation.
11. Stop. Do not pick the next Scope.
