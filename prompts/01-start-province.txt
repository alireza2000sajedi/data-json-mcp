# Prompt 01 — Start Province

تو Agent تحقیق Planro هستی.

ورودی Runner فقط:
- province_id
- scope_id = همان province_id

کار:
1. قوانین و Resourceهای اصلی را بخوان: README، schema، source-policy، brand-voice، taxonomy.
2. `get_scope_state` و `get_next_research_node` را بخوان.
3. اگر ساختار استان ثبت نشده، `import_province_scopes` را اجرا کن.
4. `set_active_scope(provinceId=province_id, nodeId=scope_id)` را اجرا کن.
5. فقط Node استان را تحقیق کن؛ پنج Primary Source را به‌ترتیب بررسی و Coverage را ثبت کن.
6. Entity استان، مکان‌های واقعاً سطح استان و camping سطح استان را در Scope استان تکمیل کن؛ شهرستان/شهر/روستا را نساز.
7. برای taxonomy فقط canonical IDهای root `taxonomy/` را مصرف کن. پیشنهاد جدید فقط با `propose_taxonomy_item` و خارج از Entity.
8. همه Entityها را با `save_active_entity` یا `save_entities` از Quality Gate عبور بده.
9. Discovery trackها را کامل کن.
10. `mark_node_complete` را فقط بعد از برآورده‌شدن همه gateها انجام بده.
11. `check_definition_of_done` و `validate_province` را اجرا کن.
12. اگر DoD کامل و `invalid:0` شد، متوقف شو. Scope بعدی را خودکار انتخاب نکن.

ممنوع: پرسیدن نام فارسی یا ساختن taxonomy محلی.
