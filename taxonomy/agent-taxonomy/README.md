# Agent Taxonomy Proposals

این پوشه یک صف پیشنهاد است، نه Taxonomy تولیدی.

Agent می‌تواند برای مفهوم واقعاً جدید یک proposal ثبت کند؛ اما حق استفاده از proposal در Entity، ایجاد taxonomy محلی در province/county/city folders یا تغییر catalog اصلی را ندارد.

Promotion فقط با تصمیم maintainer انجام می‌شود؛ بعد از promotion، Entityها باید canonical id جدید را مصرف کنند.
